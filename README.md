## ✨ Features
- 📅 **Upcoming Events Display**: Clean header with event announcements.
- 🖼️ **Photo Gallery**: Showcase event images and highlights.
- 🏷️ **Promotional Links**: Includes direct store links (e.g., Flipkart Fashion).
- 📌 **Event Highlights**: Quick info on Entry, Food, and Rules.
- 📞 **Contact Section**: Direct contact info with location details.
